Structured applications

Graphs beyond graph benchmarks.

Using relational structure in dialogue and scene understanding.

Language and structure

“On Incorporating Structural Information to Improve Dialogue Response Generation” was presented at the NLP for Conversational AI Workshop at ACL 2020, with an earlier extended abstract at EurNLP 2019. This is prior work on structured dialogue modeling; it is distinct from my emerging interest in modern LLM internals.

Dynamic scenes

Collaborative work on understanding dynamic scenes uses graph convolution networks to model relationships in scene data. Related work studies vehicle behavior classification with multi-relational graph convolutional networks.
